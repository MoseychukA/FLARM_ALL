Как собрать release APK в Android Studio

Открой проект в Android Studio, затем:

Build → Generate Signed Bundle / APK
Выбери APK
Создай новый keystore или укажи существующий
Выбери release
Включи V1 и V2 signing
Нажми Finish

Готовый файл обычно будет здесь:

app/build/outputs/apk/release/app-release.apk
Если хочешь собрать через командную строку

В корне проекта:

gradlew assembleRelease

Подписанный релиз обычно требует настройки signingConfigs в app/build.gradle.

Вот готовый пример файлов под Windows, чтобы ты просто вставил свои значения и сразу собрал release APK 👇

📄 1. keystore.properties

Создай файл в корне проекта:

storeFile=C:\\Users\\USERNAME\\keystore\\flightradar.jks
storePassword=12345678
keyAlias=flightradar
keyPassword=12345678
🔧 Пояснение:
storeFile — путь к keystore (двойные \\ обязательно)
пароли можно одинаковые (для простоты)
🔐 2. Как создать keystore (если нет)

Открой командную строку и выполни:

keytool -genkey -v -keystore flightradar.jks -alias flightradar -keyalg RSA -keysize 2048 -validity 10000

📁 Файл создастся в текущей папке
Перемести его, например, в:

C:\Users\USERNAME\keystore\
📄 3. local.properties

В корне проекта:

sdk.dir=C:\\Users\\USERNAME\\AppData\\Local\\Android\\Sdk
⚙️ 4. Проверка build.gradle (app)

У тебя должно быть примерно так:

android {
    ...

    signingConfigs {
        release {
            def keystoreProperties = new Properties()
            def keystorePropertiesFile = rootProject.file("keystore.properties")
            keystoreProperties.load(new FileInputStream(keystorePropertiesFile))

            storeFile file(keystoreProperties['storeFile'])
            storePassword keystoreProperties['storePassword']
            keyAlias keystoreProperties['keyAlias']
            keyPassword keystoreProperties['keyPassword']
        }
    }

    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
            shrinkResources false
        }
    }
}

❌ "Password incorrect"

→ проверь совпадение storePassword и keyPassword

❌ "SDK not found"

→ проверь local.properties
