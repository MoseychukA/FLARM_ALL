# Архитектура рабочей версии

## Основные модули

### UI
- `UI/MainForm.cs` — главное окно, меню, фильтры, список целей, статус-бар.
- `UI/RadarControl.cs` — круговой радар, карта, кольца дальности, треки, цели.
- `UI/SettingsForm.cs` — редактирование настроек источника, карты и тревог.

### Models
- `AircraftTarget` — текущая цель, параметры полета, точка на радаре, уровень тревоги.
- `TargetTrackPoint` — точка трека по времени.

### Services
- `DataSourceManager` — прием данных по COM/TCP/UDP.
- `FlyRfParser` — разбор строки `$FLYRF,...`.
- `TargetRepository` — текущее хранилище целей.
- `TrackHistoryService` — накопление и очистка треков.
- `TargetFilterService` — фильтрация по типам, источникам, высоте, дальности.
- `ProximityAlertService` — расчет тревог по сближению.
- `RadarRangeHelper` — шаги zoom и кольца дальности.
- `GeoHelper` — география, подписи типов и источников.
- `MapLayerService` — интерфейс карты и `OpenStreetMapTileRenderer`.

## Следующие доработки
1. Отдельная панель легенды и настройка цветов целей.
2. Прогноз точки через 30/60 секунд по курсу и скорости.
3. Поддержка своей позиции и режима `Heading Up`.
4. Асинхронная предзагрузка тайлов вокруг центра карты.
5. Поддержка офлайн-карты из каталога локальных тайлов.
6. Проверка checksum и статистика потерь пакетов.
7. Запись и воспроизведение логов.
