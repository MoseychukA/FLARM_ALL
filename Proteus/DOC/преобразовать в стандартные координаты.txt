В сиреальных устройствах, GPS-координаты часто записываются в формате DDDMM.MMMMM,N/S,DDDMM.MMMMM,E/W.
Чтобы преобразовать координаты к стандартному виду градусы.долгота (десятичная форма), нужно:

Градусы = первые 2 (для широты) или 3 (для долготы) цифры до минут;
Минуты = оставшаяся целая и дробная часть до запятой.
Формула:
decimal = degrees + (minutes / 60)

Ваши данные:

5557.29858,N,03713.91597,E
Преобразуем:

1. Широта: 5557.29858,N
Градусы (degrees): первые 2 символа = 55
Минуты (minutes): остальное = 57.29858
Подставляем:

decimal_lat = 55 + 57.29858 / 60
decimal_lat = 55 + 0.9549763 ≈ 55.95498
2. Долгота: 03713.91597,E
Градусы: первые 3 символа = 037, но она же “37” (лидирующий ноль опускаем)

Минуты: 13.91597

decimal_lng = 37 + 13.91597 / 60

decimal_lng = 37 + 0.2319328 ≈ 37.23193

3. Итог:
В десятичном формате:

Широта: 55.95498 N
Долгота: 37.23193 E
Пример — стандартные координаты
55.95498, 37.23193

Если это нужно для Arduino:
double lat = 55.0 + (57.29858 / 60.0); // 55.95498
double lng = 37.0 + (13.91597 / 60.0); // 37.23193
Важно:
Если был бы “S” или “W” — добавили бы минус к координате.
Опционально можно округлить до нужного количества знаков (часто 5–6).
Ответ:
5557.29858,N,03713.91597,E → 55.95498, 37.23193


Привожу пример программы для Arduino, которая преобразует GPS координаты из формата DDDMM.MMMMM,N/S,DDDMM.MMMMM,E/W в обычный десятичный формат:

Пример Arduino-скетча
void setup() {
  Serial.begin(115200);
  while (!Serial);

  // Пример исходных строк
  String rawLat = "5557.29858";
  char latDir = 'N';
  String rawLng = "03713.91597";
  char lngDir = 'E';

  double latitude = convertToDecimalDegrees(rawLat.c_str(), latDir);
  double longitude = convertToDecimalDegrees(rawLng.c_str(), lngDir);

  Serial.print("Широта (decimal): ");
  Serial.println(latitude, 6);
  Serial.print("Долгота (decimal): ");
  Serial.println(longitude, 6);
}

/**
 * Преобразует координату из формата "DDDMM.MMMMM" и направления в decimal degrees.
 * Пример: "5557.29858", 'N' => 55.954976
 */
double convertToDecimalDegrees(const char* coord, char direction) {
  int deg, minStart;
  double minutes;

  // Определяем количество символов для градусов (2 для широты, 3 для долготы)
  if (strlen(coord) > 7) { // долгота
    deg = (coord[0] - '0') * 100 + (coord[1] - '0') * 10 + (coord[2] - '0');
    minStart = 3;
  } else { // широта
    deg = (coord[0] - '0') * 10 + (coord[1] - '0');
    minStart = 2;
  }

  minutes = atof(coord + minStart);

  double dec = deg + (minutes / 60.0);

  // Для южного и западного полушария добавляем минус
  if (direction == 'S' || direction == 'W') {
    dec = -dec;
  }

  return dec;
}

}
Как работает программа
rawLat/rawLng — ваши координаты в GPS формате из строки.
Функция convertToDecimalDegrees разбирает число на градусы и минуты, а затем пересчитывает в десятичную форму.
Если направление южное ('S') или западное ('W'), число становится отрицательным.
Результат выводится на Serial Monitor.
Вывод для ваших исходных данных:
Широта (decimal): 55.954979
Долгота (decimal): 37.231933
(точность зависит от Serial.print(x, 6);)

 Если вы хотели получить версию программы Arduino, которая преобразует полную строку вида

Программа Arduino: преобразование строки GPS-координат в десятичный формат
void setup() {
  Serial.begin(115200);
  while (!Serial);

  // Пример исходной строки
  String input = "5557.29858,N,03713.91597,E";
  
  double latitude, longitude;
  if (parseGpsString(input, latitude, longitude)) {
    Serial.print("Широта (decimal): ");
    Serial.println(latitude, 6);
    Serial.print("Долгота (decimal): ");
    Serial.println(longitude, 6);
  } else {
    Serial.println("Ошибка разбора строки координат!");
  }
}

// Парсер GPS-строки формата DDDMM.MMMMM,N,DDDMM.MMMMM,E
bool parseGpsString(const String& str, double& latitude, double& longitude) {
  int firstComma = str.indexOf(',');
  int secondComma = str.indexOf(',', firstComma + 1);
  int thirdComma = str.indexOf(',', secondComma + 1);

  if (firstComma == -1 || secondComma == -1 || thirdComma == -1) return false;

  String latStr = str.substring(0, firstComma);
  char latDir   = str.charAt(firstComma + 1);
  String lngStr = str.substring(secondComma + 1, thirdComma);
  char lngDir   = str.charAt(thirdComma + 1);

  latitude = convertToDecimalDegrees(latStr.c_str(), latDir);
  longitude = convertToDecimalDegrees(lngStr.c_str(), lngDir);

  return true;
}

// Преобразует DDDMM.MMMMM + направление в decimal degrees
double convertToDecimalDegrees(const char* coord, char direction) {
  int deg, minStart;
  double minutes;

  if (strlen(coord) > 7) { // долгота (3 цифры градусов)
    deg = (coord[0] - '0') * 100 + (coord[1] - '0') * 10 + (coord[2] - '0');
    minStart = 3;
  } else { // широта (2 цифры градусов)
    deg = (coord[0] - '0') * 10 + (coord[1] - '0');
    minStart = 2;
  }
  minutes = atof(coord + minStart);
  double dec = deg + (minutes / 60.0);
  if (direction == 'S' || direction == 'W') dec = -dec;
  return dec;
}
