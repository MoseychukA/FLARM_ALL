Создать программа отображения движения самолетов на персональном компьютере.
Среда программирования Visual Studio 2019  C Sharp.

Входная информация (источник)поступает по КОМ порту или TCP LAN IP или UDP.
Содержимое пакета:
             snprintf_P(NMEABuffer, sizeof(NMEABuffer),
                  PSTR("$FLYRF,%06X,%d,%8s,%d,%d,%d,%d,%d,%6f,%6f,%d,%d,%d,%d,%X" FLYRF_EXT1_FMT "*"),
                  Container[i].addr,                   // Адрес устройства
                  Container[i].squawk,                 // Номер, назначаемый диспетчером для обмена с локатором.
                  Container[i].callsign,                 // Номер рейса
                  (int)Container[i].altitude,          // Высота геоид (GPS)
                  (int)Container[i].pressure_altitude, // Высота по датчику давления
                  (int)(Container[i].speed /** _GPS_MPS_PER_KNOT*/), // Скорость  km/h IAS
                  (int)Container[i].course,            // Курс в градусах
                  Container[i].vert_rate,              // Скорость подъема или снижения ft/m
                  Container[i].latitude,               // Широта
                  Container[i].longitude,              // Долгота
                  Container[i].aircraft_type,          // Тип воздушного судна
                  Container[i].signal_source,          // Источник данных (0-LoRa, 1- DUMP1090, 2 - текстовая строка из GSM или Иридиум)
                  Container[i].hour_msg,               // Время (часы) из источника 2
                  Container[i].min_msg                 // Время (минуты) из источника 2 

Экран отображения.
В центре экрана большой круг.
На кругу отметки сторон света.
На кругу через 10 градусов небольшие отметки.
На кругу через 30 градусов отметки больше.
В центре круга нарисовать графическое изображение небольшого самолета.
Добавить лист меню настроек.
В настройках указывать локальные координаты, IP адрес источника, КОМ порт источника, текущее время.
