# FlightRadarPc Diagnostic

Диагностическая версия проекта для поиска причины аварийного завершения при команде **«Показать тестовый самолет»**.

## Что изменено

- карта-подложка принудительно отключена;
- Heading Up отключен, используется только North Up;
- треки отключены в диагностическом режиме;
- тестовый самолет TEST01 добавляется напрямую в репозиторий;
- в `FlightRadarPc.log` пишутся подробные шаги:
  - старт приложения;
  - вход/выход из `ShowTestAircraft`;
  - количество целей после `SetTargets`;
  - вход/выход из `RadarControl.OnPaint`;
  - отдельные этапы отрисовки.

## Как проверять

1. Откройте проект в Visual Studio 2019.
2. Запустите приложение.
3. Выберите **Файл → Показать тестовый самолет**.
4. Если программа завершится, приложите новый файл `FlightRadarPc.log`.

## Что должно быть видно

- черный радар без карты;
- кольца дальности;
- TEST01 как крупная желтая точка;
- подпись TEST01 рядом с точкой.

## Назначение версии

Эта сборка нужна не для финальной эксплуатации, а для локализации аварийного участка: отображение, выбор цели, обновление списка или Paint.


## Исправления финальной стабильной сборки
- устранено рекурсивное падение при выборе TEST01 из списка целей;
- добавлена защита от повторного срабатывания `SelectedIndexChanged`;
- обновление UI переведено в UI-поток для `HandleLineReceived`, `RefreshRadarAndList`, `UpdateUiState`, `SelectTarget`;
- репозиторий целей сделан потокобезопасным;
- добавлены дополнительные записи в лог вокруг выбора TEST01.


Фильтры по умолчанию:
- Макс. дальность: 25 км
- Мин. высота: 0 м
- Макс. высота: 10000 м
- Только тревоги: выкл
- Только движущиеся: выкл
