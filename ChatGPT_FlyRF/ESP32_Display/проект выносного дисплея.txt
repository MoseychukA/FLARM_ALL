Есть проект базового модуля FlyRf_Base_26_04_26_14 и проект выносного дисплея FlyRf_Disp_25_12_09_00.
 Требуется создать новый проект дисплея для отображения информации на TFT дисплее аналогичной как на базовом модуле. 
 В новый проект включить файлы и информацию необходимую для создания копии экрана TFT.
 Настройки железа взять из проекта FlyRf_Disp_25_12_09_00.
 Кнопки на обеих устройствах должны выполнять одинаковые функции. 
 Функции дублируются по каналу RS485. 
 WEB интерфейс должен содержать необходимые настройки внешнего дисплея.
 Новое имя проекта внешнего дисплея FlyRf_Disp_26_04_26_00. 
Каждый новый вариант в имени проекта увеличиваем на единицу. 
Проект выдавать в архиве без вложенной папки
