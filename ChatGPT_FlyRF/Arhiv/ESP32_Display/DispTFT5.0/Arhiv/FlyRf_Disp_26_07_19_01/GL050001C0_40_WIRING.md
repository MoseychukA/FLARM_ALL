# GL050001C0-40 для FlyRf_Disp_26_07_19_01

Исходный проект: `FlyRf_Disp_26_05_18_01`.

Новая версия: `FlyRf_Disp_26_07_19_01`.

В этой версии GPIO19 и GPIO46 поменяны местами: VSYNC дисплея перенесен на GPIO19, а контроль включения питания — на входной GPIO46.

## Подключение RS485

| Сигнал преобразователя RS485 | ESP32-S3-WROOM-1-N16R8 |
|---|---|
| RO / RX | `GPIO38` (`Serial1 RX`) |
| DI / TX | `GPIO39` (`Serial1 TX`) |
| DE и /RE | `GPIO40` |
| GND | GND |

Параметры обмена: `115200 бод`, `8N1`. Выводы DE и /RE преобразователя следует объединить: низкий уровень включает приём, высокий — передачу.

Дисплей подключается к `ESP32-S3-WROOM-1-N16R8` как RGB565-панель `800x480` через периферию `esp_lcd`.

Интервалы развертки взяты из успешного теста по сигналам AMT630A. В версии 06 PCLK временно снижен для проверки устойчивости RGB DMA:

| --- | --- |

| HSYNC pulse | 64 |
| HSYNC back porch | 80 |
| HSYNC front porch | 42 |
| VSYNC pulse | 2 |
| VSYNC back porch | 34 |
| VSYNC front porch | 38 |
| Кадровая частота | около 44 Hz |

## Что сделано в версии 26_07_17_19

- Скорректированы вправо питание, `LATITUDE` и нижний GPS-блок.
- Время поднято на один уровень с обозначением `N`.
- Увеличен шрифт времени.
- GPS-блок выровнен слева, смещён влево и опущен до уровня левого блока.
- `LONGITUDE` смещён вправо, крайние поля имеют одинаковые отступы от границ.
- Нижние блоки повторяют состав исходного проекта и дополнительно опущены вниз.
- Правый GPS-блок смещён влево, время перенесено к левому краю.
- Между `LATITUDE` и `LONGITUDE` увеличено расстояние за счёт остальных колонок.
- Нижние служебные блоки привязаны к левому и правому краям и сделаны темнее.
- Колонки таблицы и разделительная линия равномерно занимают ширину экрана.
- Обозначения сторон света `N`, `E`, `S`, `W` увеличены; видимые боковые символы `W` и `E` смещены внутрь экрана.
- Удалена дополнительная строка `ALT SPEED COURSE`.
- Потеря связи отображается по центру сообщением `НЕТ СВЯЗИ С БАЗОЙ`.
- Нижние блоки опущены, а строка питания выровнена относительно изображения батареи.
- Добавлен драйвер `GL050001C0_40_Display.*`.
- Новый дисплей включён через `PROJECT_USE_GL050001C0_40 = 1`.
- Старый вывод `TFT_eSPI` не запускается при активном GL050001C0-40.
- Стартовый экран выводится через полный framebuffer `800x480 RGB565` в PSRAM.
- На панель отправляется один полный кадр через `esp_lcd_panel_draw_bitmap()` за одно обновление.
- Через три секунды рабочая страница передаётся один раз и фиксируется.
- Геометрия рабочего экрана сохранена от версии 05.
- Снижение PCLK уменьшает поток чтения RGB565 из PSRAM с 64,5 до 48 МБ/с.
- На ESP32 Arduino core 3.x используется bounce-буфер высотой 20 строк; core 2.0.11 собирается без этого недоступного поля.
- Подсветка на `GPIO21` при старте включается в максимальную яркость обычным уровнем HIGH.
- Для проверки устойчивости включены RS485 и рабочая страница, но отключены Wi-Fi и Web.
- Внешняя шкала радара повторяет исходный проект: 36 отдельных рисок без сплошной внешней окружности.
- Красная рамка диапазона `32 km` масштабирована из исходных координат `(216,302,56,17)` в `(364,453,84,26)`.
- Предупреждение потери связи больше не закрывает радар и отображается в верхней строке.
- Верхняя строка и таблица целей больше не имеют серой заливки и голубых полос.
- С заставки удалена оранжевая надпись `POWER`.
- Исправлены сглаженные шрифты рабочего экрана; текстовые блоки снова имеют видимые глифы.
- Символ собственного самолёта рисуется чистым белым цветом.
- Текст таблицы и служебных блоков сделан белым, а окружности и риски радара стали ярче.
- Таблица целей содержит девять полей исходного проекта и выводится компактным сглаженным шрифтом.
- После фиксации рабочего кадра прекращается повторная подготовка состояния дисплея.

## Примечание

Основная радарная страница масштабирована из исходных координат `480x320` в область `720x480`. После прошивки необходимо проверить отсутствие мерцания и соответствие размеров исходному экрану.
