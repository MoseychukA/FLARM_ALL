# FlyRf_Disp_26_07_19_04

Исходный проект: `FlyRf_Disp_26_05_18_01`.

## Назначение версии

- проект полностью основан на исходнике без замены RS485, Wi-Fi, Web, EEPROM, TrafficDB и основного цикла;
- старый TFT заменен на RGB-дисплей GL050001C0-40;
- на дисплей выводится только неподвижная стартовая страница;
- формирование и вывод рабочего экрана временно заблокированы;
- кнопка, INA219, питание и обработка принятых данных продолжают обслуживаться;
- Wi-Fi и Web-интерфейс включены так же, как в исходном проекте.

## Аппаратные изменения

- VSYNC дисплея: `GPIO19`;
- контроль включения питания: `GPIO46`;
- кнопка: `GPIO42`;
- удержание питания: `GPIO41`;
- подсветка AP3032: `GPIO21`;
- INA219: SDA `GPIO8`, SCL `GPIO9`;
- RS485 оставлен без изменений: RX `GPIO38`, TX `GPIO39`, DE `GPIO40`.

Сборка предназначена для ESP32 Arduino `2.0.11`, поскольку на этой версии подтверждена стабильная работа RGB-панели.
