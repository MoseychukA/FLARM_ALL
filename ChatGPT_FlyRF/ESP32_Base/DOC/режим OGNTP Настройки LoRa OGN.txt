режим OGNTP описан не как LoRa, а как RF_MODULATION_TYPE_2FSK. Поэтому часть параметров headerMode/LoRa CRC для него напрямую не применяется.

Думал на протяжении 2m 14s

По архиву FlyRf_Base_26_05_04_05.zip параметры OGNTP / OGN находятся в OGNTP.h и OGNTP.cpp.

Главное: в этом проекте режим OGNTP не LoRa, а 2-FSK:

.modulation_type = RF_MODULATION_TYPE_2FSK

Поэтому параметры headerMode = explicit/implicit и обычный LoRa CRC к OGNTP напрямую не относятся.

Параметры OGNTP из проекта
Параметр	Значение
Modulation	2-FSK, не LoRa
crcOn / CRC mode	аппаратный LoRa CRC не используется; в протоколе стоит RF_CHECKSUM_TYPE_GALLAGER
CRC size	6 байт
preambleLen	1 байт, тип 0xAA
syncWord	AA 66 55 A5 96 99 96 5A
syncWord size	8 байт
headerMode	для OGNTP не explicit/implicit; это FSK packet mode, фактически фиксированная длина
payload size	20 байт
полный пакет FSK	20 + 6 CRC = 26 байт
bitrate	100 kbps
deviation	±50 kHz
whitening / coding	Manchester
RX bandwidth	125 kHz

Из OGNTP.h:

#define OGNTP_PREAMBLE_TYPE   RF_PREAMBLE_TYPE_AA
#define OGNTP_PREAMBLE_SIZE   1
#define OGNTP_SYNCWORD        {0xAA, 0x66, 0x55, 0xA5, 0x96, 0x99, 0x96, 0x5A}
#define OGNTP_SYNCWORD_SIZE   8
#define OGNTP_PAYLOAD_SIZE    20
#define OGNTP_CRC_TYPE        RF_CHECKSUM_TYPE_GALLAGER
#define OGNTP_CRC_SIZE        6

syncWord: нет, не 0xFF. В этом проекте синхронизация OGNTP — это 8 байт:

0xAA, 0x66, 0x55, 0xA5, 0x96, 0x99, 0x96, 0x5A

В комментарии проекта указано:

IEEE Manchester(0AF3656C) = AA 66 55 A5 96 99 96 5A
Если всё-таки говорить про LoRa-профиль в коде

В LoRa-ветке проекта параметры задаются через LMIC.rps. Там везде используется:

makeRps(..., ih = 0, nocrc = 0)

То есть для LoRa это означает:

LoRa параметр	Значение
crcOn	true, потому что nocrc = 0
headerMode	explicit, потому что ih = 0
preambleLen	8 символов в SX1276 LoRa RX-коде
syncWord	берётся как LMIC.protocol->syncword[0]

Но для штатного OGNTP это не применяется, потому что OGNTP выбран как RF_MODULATION_TYPE_2FSK.

Итог: для режима OGN из этого проекта нужно ориентироваться не на LoRa 0xFF / explicit / implicit, а на FSK OGNTP:

CRC:        Gallager, 6 bytes; hardware LoRa CRC не используется
Preamble:   0xAA, nominal 1 byte
SyncWord:   AA 66 55 A5 96 99 96 5A
HeaderMode: не LoRa; FSK fixed packet mode
