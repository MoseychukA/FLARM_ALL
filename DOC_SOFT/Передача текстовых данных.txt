Передача текстовых данных параметров стороннего самолета

#  
1    // Номер сообщения
#
SET  // Признак записи, передачи КОМАНДЫ
#
FLY  // Команда передачи данных параметров стороннего самолета
#
addr,                   // Адрес устройства (строка, в программе переводится в HEX 6 знаков)
Squawk,                 // Номер, назначаемый диспетчером для обмена с локатором. 4 знака
flight,                 // Номер рейса (7 знаков)
altitude,               // Высота геоид (GPS) float не более 7 знаков
pressure_altitude,      // Высота по датчику давления  7 знаков
speed,                  // Скорость (уточню в каких попугаях meters per second) 6 знаков
course,                 // Курс в градусах 6 знаков
vert_rate,              // Скорость подъема или снижения (уточню в каких попугаях) 4 знака
latitude,               // Широта 10 знаков
longitude,              // Долгота 10 знаков
aircraft_type           // Тип воздушного судна 1 знак

Все данные отделяются запятой

Пример Зеленоградский лесопарк:
#1#SET#FLY#3B3CB1,1234,SMD6406,100,105,600,180,40,56.005065,37.177184,7,10,10

При верных параметрах в ответ придет сообщение!
OK FLY|OK

Неверные параметры:
#1#SET#FLY#3B3CB1,1234,SMD6406,100,105,600,180,40,56.005065,37.177184 (нет типа воздушного судна)
ERR FLY|BAD_PARAMS
