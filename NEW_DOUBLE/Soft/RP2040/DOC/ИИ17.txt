Спасибо, это просто: в вашей сборке компилятор видит вызов feed_sample_and_filter(ps, bit) раньше, чем видит её объявление.
 В Arduino с автогенерацией прототипов иногда пропускаются inline/статические функции, поэтому нужен явный прототип либо перестановка.

Быстрое исправление у себя

В файле adsb_rp2040_adsb.ino:

Найдите блок определения структуры PreambleState:
struct PreambleState { ... };
и сразу после него вставьте одну строку с прототипом:
static inline void feed_sample_and_filter(PreambleState& ps, bool s);

Проверьте, что в цикле rx_task() после вызова feed_sample_and_filter стоит точка с запятой:
feed_sample_and_filter(ps, bit);
Если её нет — добавьте. Иначе компилятор сочтёт это началом следующего токена и “поползёт” с синтаксическими ошибками ниже.

Альтернатива: перенесите сами определения вспомогательных функций выше

Переместите весь блок с этими функциями выше объявления rx_task:

static inline void shift_in_bit(...)
static inline void push_pulse(...)
static inline bool peek_pulse(...)
static inline void feed_sample_and_filter(...)
static bool corr_preamble_and_get_t0(...)
static bool demod_bits(...)
Главное, чтобы компилятор увидел либо прототипы, либо определения до места первого использования в rx_task().
