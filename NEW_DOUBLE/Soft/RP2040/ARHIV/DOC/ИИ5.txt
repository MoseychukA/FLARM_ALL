Что изменилось

Gillham при Q=0: реализована функция decode_altitude_gillham(ac13). Преобразует код AC13 в высоту в футах, возвращает -1 при некорректном коде.
TC=19 расширен:
Подтипы 1/2: векторная скорость по осям EW/NS → ground speed и курс.
Подтип 3: курс/наземная скорость.
Подтип 4: курс/истинная воздушная скорость.
Поля вертикальной скорости и баро-гео разности помечены как placeholders (в TC=19 они не всегда доступны; обычно приходят из BDS 6,0/6,1).
UART2: 921600 бод остаётся.
Остальной функционал: DMA кольца на три канала, весовая корреляция преамбулы, цифровой фильтр 0.4–0.7 мкс, CPR global/local с учётом времени even/odd.
Структура

adsb_rp2040_adsb/
adsb_rp2040_adsb.ino — основной скетч (DMA, коррелятор, расширенный TC=19, Gillham)
adsb_sampler.pio — PIO-программа семплинга
dma_ring.h, dma_ring.cpp — DMA-кольца для PIO RX FIFO
adsb_crc.h — CRC-24 (таблица 256 значений) + 1-бит коррекция
adsb_decoder.h, adsb_decoder.cpp — декодер (callsign, CPR global/local, TC19 расширенный, Gillham)
docs/ARCH_DMA_v2.md — заметки по версии
Как обновить у себя

Замените предыдущую версию проектом из архива v2.
Откройте папку adsb_rp2040_adsb в Arduino IDE, соберите с теми же настройками.
При необходимости выставьте опорную точку CPR_REF (координаты приёмника) в adsb_rp2040_adsb.ino.
Замечания

Gillham: реализован обобщённый декодер AC13; при необходимости можно строго сверить с эталонной таблицей и доработать обработку исключительных кодов (высота ниже -1000/выше 126000 футов).
Вертикальная скорость и баро-гео разность: для их надёжного извлечения пригодится декод BDS 6,0/6,1 (не всегда доступно в DF17/ME=19). Могу добавить полноценный парсер этих отчетов при необходимости.
