Comm‑B BDS 6,0/6,1:
BDS 6,0: извлечение барометрической и инерциальной вертикальных скоростей (единицы 64 fpm, корректировка −1).
BDS 6,1: извлечение разности геометрической и барометрической высоты (единицы 25 ft).
Данные интегрируются в поля VS и BG (baro‑geo) для всех режимов вывода (CSV/NMEA/JSON/UBX).
Постоянные настройки (LittleFS):
Команды SAVE/LOAD/SHOW по Serial2.
Сохраняются: формат вывода (MODE), профиль (PROFILE), дубль CSV (LOG), опорная точка REF(lat/lon).
Всё остальное — как в v2.2: DMA-кольца, адаптивный коррелятор Variant B, CPR global/local, Gillham(Q=0), TC=19 1/2/3/4, UART2 921600 бод, форматы RAW/CSV/NMEA/JSON/UBX.
Команды по Serial2

MODE CSV|NMEA|JSON|UBX|RAW
PROFILE NORMAL|EMI
LOG ON|OFF
REF
SAVE / LOAD / SHOW
HELP
Заметки

Для работы LittleFS: в Arduino Core RP2040 поддержка включена. Первый SAVE создаст файл /config.txt в Flash. LOAD восстановит настройки при последующих перезагрузках (в коде LOAD не выполняется автоматически при старте; можно добавить автозагрузку, если нужно).
Парсер BDS 6,x ориентирован на наиболее распространённые раскладки полей; в редких реализациях EHS могут отличаться битовые позиции — при необходимости адаптируем.
Если хотите:

Автозагрузка настроек при старте,
Больше профилей (например, Urban/Remote),
Поддержку DF18, TIS‑B/MLAT маркировки,
собрать v2.4 и перезалить.
