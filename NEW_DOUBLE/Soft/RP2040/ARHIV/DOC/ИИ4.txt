Что нового

PIO → DMA: каждый из 3 PIO state machine пишет в свой кольцевой буфер через DMA. CPU больше не опрашивает RX FIFO.
Коррелятор преамбулы: весовая корреляция по 80 отсчетам с маской подавления ложных срабатываний.
Цифровой фильтр: пороги 0.4–0.7 мкс, нормализация до 0.5 мкс, отбрасывание коротких/длинных импульсов.
CPR: добавлена локальная декодировка (по опорной точке приёмника) и глобальная (even/odd с учетом времени в окне 10 с).
Скорость TC=19: поддержаны подтипы 1/2 (векторная скорость), 3/4 (курс/наземная, курс/истинная).
Высота: каркас для декодирования Gillham при Q=0 (заглушка gillham2alt() помечена для завершения реализации).
Serial2: скорость поднята до 921600 бод.

Как использовать

Распакуйте архив.
Откройте в Arduino IDE папку adsb_rp2040_adsb как скетч.
Плата: Raspberry Pi Pico (RP2040), ядро Earle Philhower 3.7.2.
Библиотека: FreeRTOS_RP2040 (Khoih-prog) v1.3.2.
Tools: CPU 250 MHz, Optimize Most (-O3), USB Stack Pico SDK.
Подключения: входы 18/19/22; индикаторы 17/20/23; RSSI — 26; UART2 TX/RX — 4/5.
Скорость UART2: 921600 бод.
При желании задайте опорную точку CPR_REF в adsb_rp2040_adsb.ino под координаты вашего приёмника.
Примечания

Функция Gillham (Q=0) оставлена как заготовка: для полной совместимости добавьте корректную таблицу декодирования AC13 в gillham2alt().
При сильных помехах можно усилить пороги корреляции в corr_preamble_and_get_t0().
Размер DMA-колец сейчас 1024 слова на канал: при необходимости увеличьте.
Нужно включить gillham2alt() полностью или добавить ещё типы TC=19? Скажете — обновлю архив и перезалью.
