
# ADS-B RP2040 FreeRTOS Receiver (DMA + 3 channels)

Изменения:
- PIO -> DMA в кольцевые буферы (по одному DMA на каждый SM)
- Надёжная весовая корреляция преамбулы и помехозащищённая маска
- CPR: глобальная и локальная (учёт времени even/odd), параметр опорной точки
- Скорости: TC=19 (подтипы 1/2/3/4)
- Высота: поддержка Gillham при Q=0
- UART2: 921600 бод

Проверено: Arduino IDE 2.3.2, Earle Philhower RP2040 core 3.7.2, FreeRTOS_RP2040 1.3.2
