Как использовать
Распакуйте архив.
В Arduino IDE откройте папку adsb_rp2040_adsb как скетч.
Плата: Raspberry Pi Pico (RP2040), ядро Earle Philhower 3.7.2.
FreeRTOS_RP2040 (Khoih-prog) v1.3.2 через Library Manager.
Tools: CPU 250 MHz, Optimize Most (-O3), USB Stack Pico SDK.
Подключения: RX каналы — GPIO18/19/22; LED — GPIO17/20/23; RSSI — GPIO26; Serial2 TX/RX — GPIO4/5 (230400 бод).
Прошейте и контролируйте вывод по UART2.
