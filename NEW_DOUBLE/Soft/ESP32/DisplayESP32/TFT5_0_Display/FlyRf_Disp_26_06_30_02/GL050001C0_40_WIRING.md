# GL050001C0-40 для FlyRf_Disp_26_06_30_02

Целевой модуль: `ESP32-S3-WROOM-1-N16R8`, Flash 16 МБ, PSRAM 8 МБ.

Дисплей подключается как RGB565-панель 800x480 через периферию RGB LCD
ESP32-S3 (`esp_lcd`). Нумерация контактов приведена для 40-контактного
разъёма дисплея. Перед изготовлением платы необходимо проверить сторону
контактов и положение контакта 1 выбранного FPC-разъёма.

GPIO21 управляет входом `DISP`. Он не подключается к VLED+ или VLED-.
Подсветка должна питаться от отдельного драйвера постоянного тока.

Младшие разряды `R0-R2`, `G0-G1` и `B0-B2` не используются интерфейсом
RGB565 и подключаются к GND. Вход `NC` оставляется неподключённым.

## Другие сигналы проекта

| Назначение | GPIO ESP32-S3 |
| --- | --- |
| BOOT | GPIO0 |
| U0TXD | GPIO43 |
| U0RXD | GPIO44 |
| RS485 RX | GPIO38 |
| RS485 TX | GPIO39 |
| RS485 DE | GPIO40 |
| Кнопка 1 | GPIO45 |
| Удержание питания | GPIO17 |
| INA219AIDR SDA | GPIO8 |
| INA219AIDR SCL | GPIO9 |

Адрес INA219AIDR по умолчанию: `0x40`. GPIO8 и GPIO9 дисплеем не
используются. GPIO46 оставлен в резерве.

Все земли ESP32-S3, дисплея, INA219AIDR и драйвера подсветки должны быть
соединены. Нельзя подавать RGB-сигналы при выключенном питании VDD дисплея.

## Что изменено в версии 26_06_30_02

- Имя проекта увеличено до `FlyRf_Disp_26_06_30_02`.
- Добавлена полная таблица контактов разъёма дисплея 1-40.
- GPIO21 обозначен в программе как `DISP`, а не как питание подсветки.
- Зафиксировано подключение RGB565 к старшим разрядам RGB-интерфейса.
- Контакты резистивного сенсора оставлены неподключёнными.

## Настройки Arduino

Выберите плату ESP32-S3 с Flash 16 МБ и включённой OPI PSRAM 8 МБ.

```powershell
arduino-cli compile `
  --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi" `
  --libraries "FlyRf_Disp_26_06_30_02/libraries" `
  "FlyRf_Disp_26_06_30_02"
```
