# GL050001C0-40 для FlyRf_Disp_26_06_30_00

Целевой модуль: `ESP32-S3-WROOM-1-N16R8`.

Модуль имеет 16 МБ Flash и 8 МБ PSRAM. Для RGB-дисплея 800x480 PSRAM нужна
для кадрового буфера, потому что обычной внутренней RAM ESP32-S3 для этого
недостаточно.

Дисплей `GL050001C0-40` подключается как raw RGB565-панель 800x480 через
RGB LCD периферию ESP32-S3 (`esp_lcd`). В проекте включён флаг
`PROJECT_USE_GL050001C0_40`, поэтому старый путь вывода через `TFT_eSPI`
для дисплея обходится.

## Использованная распиновка дисплея

Для RGB565 требуется 16 линий данных, 4 линии синхронизации и управление
подсветкой. По вашему списку свободных GPIO хватает без применения `GPIO8`
и `GPIO9`; они оставлены в резерве.

## Что изменено в программе

Файлы дисплея:

| Файл | Назначение |
| --- | --- |
| `GL050001C0_40_Display.h` | интерфейс модуля дисплея |
| `GL050001C0_40_Display.cpp` | инициализация RGB-панели и простой экран состояния |
| `ProjectHardware.h` | целевой модуль, Flash/PSRAM и флаг `PROJECT_USE_GL050001C0_40` |

В `ESP32RF.cpp` добавлен режим работы с `GL050001C0-40`:

- при старте вызывается `GL050001C0_40_setup()`;
- выводится стартовый экран `DECIMA / STARTING`;
- в цикле выводится базовый экран состояния с RX/TX счётчиками;
- при выключении выводится экран `POWER OFF / PLEASE WAIT`;
- старый TFT_eSPI sprite-интерфейс не выполняется, пока включён
  `PROJECT_USE_GL050001C0_40`.

Полный перенос старого радарного интерфейса 480x480 на 800x480 RGB ещё требует
отдельной переработки графического слоя: старые `TFT_eSPI` sprite/font-вызовы
нужно заменить на отрисовку через новый RGB backend.

## Настройки Arduino

Выбирайте плату ESP32-S3 с Flash 16 МБ и включённой PSRAM. Для Arduino CLI
целевая сборка выглядит так:

```powershell
arduino-cli compile `
  --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi" `
  --libraries "FlyRf_Disp_26_06_30_00/libraries" `
  "FlyRf_Disp_26_06_30_00"
```

Если в установленном ESP32 Arduino Core пункт PSRAM называется иначе, выберите
вариант, который включает 8 МБ PSRAM модуля `ESP32-S3-WROOM-1-N16R8`.
