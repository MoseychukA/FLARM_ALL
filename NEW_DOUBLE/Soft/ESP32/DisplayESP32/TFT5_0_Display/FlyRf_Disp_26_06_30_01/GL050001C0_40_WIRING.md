# GL050001C0-40 для FlyRf_Disp_26_06_30_01

Целевой модуль: `ESP32-S3-WROOM-1-N16R8`.

Модуль имеет 16 МБ Flash и 8 МБ PSRAM. Для RGB-дисплея 800x480 PSRAM нужна
для кадрового буфера, потому что обычной внутренней RAM ESP32-S3 для этого
недостаточно.

Дисплей `GL050001C0-40` подключается как raw RGB565-панель 800x480 через
RGB LCD периферию ESP32-S3 (`esp_lcd`). В проекте включён флаг
`PROJECT_USE_GL050001C0_40`, поэтому старый путь вывода через `TFT_eSPI`
для дисплея обходится.

## Занятые выводы, не применяемые для дисплея

Эти линии уже заняты проектом или нужны для загрузки/отладки:

| Сигнал | GPIO |
| --- | --- |
| BOOT | GPIO0 |
| U0TXD | GPIO43 |
| U0RXD | GPIO44 |
| RS485 RX | GPIO38 |
| RS485 TX | GPIO39 |
| RS485 DE | GPIO40 |
| Кнопка 1 | GPIO45 |
| Удержание питания | GPIO17 |
| INA219AIDR SDA | GPIO8 |
| INA219AIDR SCL | GPIO9 |

INA219AIDR восстановлен на I2C-шине `GPIO8/GPIO9`, адрес по умолчанию
`0x40`. В коде это задано в `ProjectHardware.h`:

```cpp
#define PROJECT_PIN_I2C_SDA       8
#define PROJECT_PIN_I2C_SCL       9
#define PROJECT_INA219_I2C_ADDR   0x40
```

В `FlyRf_Disp_26_06_30_01.ino` шина запускается явно:

```cpp
Wire.begin(PROJECT_PIN_I2C_SDA, PROJECT_PIN_I2C_SCL);
```

## Использованная распиновка дисплея

Для RGB565 требуется 16 линий данных, 4 линии синхронизации и управление
подсветкой. `GPIO8` и `GPIO9` не используются дисплеем, потому что возвращены
под INA219AIDR.

## Что изменено в версии 26_06_30_01

- Имя проекта увеличено на единицу: `FlyRf_Disp_26_06_30_01`.
- `INA219AIDR` восстановлен на I2C `GPIO8/GPIO9`.
- Дисплей `GL050001C0-40` не использует `GPIO8/GPIO9`.
- Распиновка RGB-дисплея сохранена на остальных свободных GPIO.

## Настройки Arduino

Выбирайте плату ESP32-S3 с Flash 16 МБ и включённой PSRAM. Для Arduino CLI
целевая сборка выглядит так:

```powershell
arduino-cli compile `
  --fqbn "esp32:esp32:esp32s3:FlashSize=16M,PSRAM=opi" `
  --libraries "FlyRf_Disp_26_06_30_01/libraries" `
  "FlyRf_Disp_26_06_30_01"
```

Если в установленном ESP32 Arduino Core пункт PSRAM называется иначе, выберите
вариант, который включает 8 МБ PSRAM модуля `ESP32-S3-WROOM-1-N16R8`.
