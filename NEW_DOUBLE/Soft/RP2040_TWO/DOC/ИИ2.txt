Чтобы вывести в Serial содержимое пакета rx_enqueue(*pkt) в HEX формате, нужно вставить в вашу функцию ADSB_OnRawPacket() в adsbee.cpp следующий код:

#include <stdio.h> // уже есть, если нет — добавьте

// В вашем файле adsbee.cpp перед вызовом rx_enqueue(*pkt)
extern "C" void ADSB_OnRawPacket(Raw1090Packet* pkt) {
    // Вывести содержимое пакета в HEX
    Serial.printf("Пришли пакет (HEX): ");
    for (int i = 0; i < Raw1090Packet::kMaxPacketLenWords32; ++i) {
        Serial.printf("%08X ", pkt->buffer[i]);
    }
    Serial.println();

    // затем уже
    g_stat_enq++;
    rx_enqueue(*pkt);
}
Обратите внимание:

Этот код выводит полностью все 4 слова буфера buffer[4] в HEX.
В конце — добавляется Serial.println(), чтобы отделить один пакет от другого.
Убедитесь, что Serial инициализирован и активен, иначе вывод не появится.
Если нужно — я подготовлю более подробное или форматированное отображение (например, по байтам или с порядком битов).
