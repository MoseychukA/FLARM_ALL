Для передачи принятых пакетов (через raw_1090_packet_queue.Push(rx_packet_[sm_index]))
 в основную программу (например, для обработки, декодирования, вывода и т. п.) нужно:

Использовать очередь сообщений (msg queue) или буфер, которые созданы для межпоточной передачи данных 
(например, LockFreePacketQueue или свой собственный механизм очереди).

В вашем случае — очевидно, пакет успешно захвачен и помещен в raw_1090_packet_queue.Push(rx_packet_[sm_index]).
Далее — получить его из этой очереди и обработать.

Как реализовать
В основном основном цикле (или внутри ядра 0, если обработка на нём) — вызываете pop() из очереди, например:
Raw1090Packet rx_pkt;
if (raw_1090_packet_queue.pop(rx_pkt)) 
{
    // В этом месте у вас есть принятый пакет rx_pkt
    process_rx_packet(rx_pkt); // Ваша функция обработки, декодирования
}
Вызов pop() возвращает true, если есть пакет, и заполняет rx_pkt. Тогда можно сразу его анализировать.
Что нужно:
Обеспечить правильную работу этой очереди:

Она должна быть потокобезопасной или с другим механизмом межпоточной синхронизации.
В вашем проекте — карточкой служит LockFreePacketQueue (или подобная).
Пример вызова:

Raw1090Packet rx_packet;
if (raw_1090_packet_queue.pop(rx_packet)) 
{
    // дальше — анализ и обработка
    handle_rx_packet(rx_packet);
}
В функции handle_rx_packet(&) — сделаете декодирование и вывод.
Важный момент:
После получения пакета — его нужно разобрать по структуре.
Передача данных через очередь — предпочтительнее, чем глобальные переменные.

Отлично. Вот пример функции construct_raw_message_from_rx_buffer(), 
которая превращает сырые данные (rx_buffer) из пакета Raw1090Packet в структуру RawMessage,
 чтобы далее можно было вызвать decode_adsb_frame() и получить координаты, скорость и другую информацию.

bool construct_raw_message_from_rx_buffer(const Raw1090Packet &pkt, RawMessage &rm) {
    // В этом примере предполагается, что rx_buffer содержит сырые байты 
    // (например, кадр ADS-B в виде битов или слов).
    // Вам нужно понять точный формат, и преобразовать его в RawMessage.

    // Пример: считаем, что rx_buffer содержит 56- или 112-битный пакет (разбить байты)

    // Проверка длины
    if (pkt.rx_buffer_len_words32 == 0) return false;

    // Допустим, что rx_buffer сразу содержит байты (подразумевается конвертация из слов)
    // Создадим временный буфер байт
    uint8_t buf[1024]; // максимум
    size_t byte_len = pkt.rx_buffer_len_words32 * 4; // слова в байты

    // Копируем из rx_buffer в буфер байтов
    for (size_t i=0; i<pkt.rx_buffer_len_words32; i++) {
        uint32_t word = pkt.rx_buffer[i];
        buf[i*4 + 0] = (word >> 0) & 0xFF;
        buf[i*4 + 1] = (word >> 8) & 0xFF;
        buf[i*4 + 2] = (word >> 16) & 0xFF;
        buf[i*4 + 3] = (word >> 24) & 0xFF;
    }

    // Инструкция: определить, есть ли действительно пакет, например, по старт‑байту или префиксу.
    // В чистом виде — принять весь буфер до длины, указанной в rx_buffer_len_words32.
    // В реальности — по формату пакета (например, кадру ADS-B) ищем преамбулу.

    // В данном случае, сделайте простую проверку, и сконвертируйте байты в RawMessage:
    // Это — упрощенная версия, вам надо адаптировать под конкретный формат.

    // В этом примере — полностью копируем буфер в RawMessage
    memset(&rm, 0, sizeof(rm));
    size_t payload_bytes = (byte_len >= 14) ? 14 : byte_len; // максимум 14 байт (112 бита)
    memcpy(rm.payload, buf, payload_bytes);
    rm.bytes = payload_bytes;
    rm.bits = payload_bytes * 8;
    // В реальности, нужно считать правильное положение, CRC и длину пакета, исходя из протокола.

    // Пример: если есть стандартная преамбула, поиск её по буферу и установка t0 (при наличии)
    // Пока предполагаем, что всё в порядке.
    return true;
}
