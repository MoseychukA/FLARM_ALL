Готово. Собрал вариант “полностью без PIO/DMA” — с прерываниями GPIO на 17, 19, 22 и временными метками фронтов.

Файл архива: adsb_rp2040_gpio_irq_nodma.zip

Что внутри и как это работает

GPIO IRQ:

Настроены входы: pin 17 (CH1), pin 19 (CH2), pin 22 (CH3).
Включены прерывания по обоим фронтам (rise/fall).
Обработчик gpio_irq_handler() записывает в кольцевой буфер только пару (t_us, level) для соответствующего канала:
t_us = time_us_32()
level = 1 (rise) или 0 (fall)
ISR кратчайший — минимальные задержки.
Edge-based коррелятор/слайсер:

В ringbuffer.cpp: run_edge_correlator_and_slice() просматривает последние достижения в окне и пытается обнаружить преамбулу по характерным коротким интервалам при нашей «грубой» дискретизации таймера.
После удачной детекции грубо нарезает 112 бит (подготовка под 56/112 — при необходимости добавлю эвристику остановки после 56).
Эта версия — упрощённая (без весовой корреляции и тонкого окна). Её цель — показать работоспособный шаблон с GPIO IRQ. При желании усилю по вашим параметрам (строгие проверки интервалов, маски, dead time, и т.д.).
Декодирование:

adsb_decoder.* — базовые функции: DF/TC, callsign, CRC и исправление одного бита. Остальные поля (позиция, высота и т.п.) можно нарастить потом (как в DMA‑версии).
Serial:

USB 115200 (ожидание до 8 сек, чтобы гарантированно увидеть “GPIO IRQ no-DMA start” в мониторе).
Serial2 921600 (TX=4 RX=5) — на ESP32‑S3 (TX=GPIO41, RX=GPIO42).
Команды USB:

HELP, SHOW, SAVE, LOAD, RAW ON|OFF.
Важно

Эта версия не использует PIO вообще: проще отлаживать и не будет “штормов IRQ” из‑за постоянной готовности RX FIFO.
Таймер RP2040 даёт разрешение 1 мкс — для точной детекции 0.5 мкс импульсов потребуется добавить небольшой числовой фильтр/агрегацию (например, отбрасывать джиттер, анализировать ширину импульсов по паре фронтов). В этой версии для простоты заложены широкие допуски.
Если фронтов много (помехи), буфер 4096 записей на канал может переполняться — можно увеличить размер (EDGE_BUF_SIZE) или уменьшить шум за счёт подтяжек/фильтра.
Рекомендации для запуска

Полярность входов: по умолчанию gpio_pull_down(); если ваш приёмник “active-low”, замените на gpio_pull_up() и (при необходимости) я добавлю флаг инверсии уровня.
Начните с одного канала (подключите сигнал к pin 17) и проверьте:
Есть ли поток фронтов (можно добавить счётчик в ISR).
Включите RAW ON — должны появляться строки CHx 112b ... Если нет — пришлите лог, добавлю отладочные печати по фронтам/интервалам.
Готов добавить

Улучшенный коррелятор по временам: точные проверки dAB/dBC/dCD, dead time, маски помех, пороги для high‑EMI.
Опцию инверсии входа (команда INVERT CH1/CH2/CH3).
Автопереход на 56 бит, если “вторая половина пустая”.
CPR/TC19/Gillham как в версии DMA.
Малый цифровой фильтр по фронтам (например, игнорировать импульсы <0.3 мкс по двум фронтам подряд).
Если хотите — сделаю сразу “v2” этого пакета с усиленной детекцией и всеми декодами.
