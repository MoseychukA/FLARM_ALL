Разберём по шагам, почему может “не работать Serial USB” на RP2040 и как быстро починить.

Проверьте настройки платы в Arduino IDE (Earle Philhower RP2040 core)

Board: Raspberry Pi Pico (или ваша плата на RP2040).
Tools →
USB Stack: TinyUSB
USB CDC on Boot: Enabled
Upload Method: Default (UF2)
Debug Port: Disabled (или Serial)
CPU Speed: по умолчанию
Filesystem (если есть): LittleFS — можно оставить
В Arduino IDE откройте Monitor на 115200.
Проверьте “железо”

Кабель точно “DATA”, а не зарядный.
После прошивки COM‑порт может смениться — закройте/откройте монитор.
На Windows иногда помогает кабель в другой порт USB или отключение энергосбережения USB.
Небольшой патч в скетче (улучшить ожидание USB)
В начале setup() замените ожидание USB на более “терпеливое” (8–10 секунд) с учётом DTR. Это устраняет ситуацию, когда ПК не успевает открыть порт:

было:
Serial.begin(115200);
while(!Serial && millis() < 2000) {}

сделайте так:
Serial.begin(115200);
unsigned long t0 = millis();
while(!Serial && !Serial.dtr() && (millis() - t0) < 8000) {
delay(10);
}
Serial.println("USB ready");

Пояснения:

!Serial.dtr() даёт понять, что монитор ещё не “подцепился”.
Ожидаем до 8 сек, потом всё равно идём дальше (не висим навсегда).
После подключения монитора Serial начнёт печатать.
Быстрый тест “чистым” скетчем
Перед сборкой большого проекта проверьте USB таким минимальным скетчем:

void setup() {
pinMode(25, OUTPUT); // LED на Pico
digitalWrite(25, 1);
Serial.begin(115200);
unsigned long t0 = millis();
while (!Serial && !Serial.dtr() && (millis() - t0) < 10000) delay(10);
Serial.println("Hello from RP2040");
}
void loop() {
static uint32_t t=millis();
if (millis() - t > 1000) { t = millis(); Serial.println("tick"); digitalWrite(25, !digitalRead(25)); }
}

Если этот скетч работает (USB появляется, сообщения идут), значит с драйвером/настройками всё ОК — возвращаемся к проекту.

Частые причины “тихого” Serial в больших проектах

Выбран не тот USB Stack (не TinyUSB) или CDC on Boot = Disabled — тогда Serial уедет на UART, а по USB не появится ничего. Обязательно включите.
Окно ожидания USB слишком короткое (2 секунды). См. патч.
Монитор IDE не был открыт после прошивки (а вы печатаете только в setup). Откройте монитор — и печатайте ещё и в loop.
После прошивки COM‑порт сменился — откройте заново нужный порт.
Кабель “зарядный” (только питание) — замените на DATA.
