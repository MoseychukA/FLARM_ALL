Настройки сборки в Arduino IDE (RP2040 core 4.7.1)
Board: Raspberry Pi Pico
CPU: 200–250 MHz (можно 250 MHz)
Optimize: Optimize Even More (-O3) или Small (-Os) — на ваше усмотрение
USB Stack: Pico SDK
Upload Method: Default (UF2) или Picotool (если копирование на RPI-RP2 даёт ошибку)
Библиотеки:
FreeRTOS (идёт с RP2040 core 4.7.1)
LittleFS (идёт с RP2040 core 4.7.1)
Подключения и скорости
Serial (USB CDC): 115200 бод (лог/команды)
Serial2 (UART): TX GPIO4, RX GPIO5, 921600 бод (обмен с ESP32S3)
Входы ADS-B: GPIO18, GPIO19, GPIO22
Индикация преамбулы: GPIO17, GPIO20, GPIO23
RSSI (ADC): GPIO26
Периодические мигания:
Core0 GPIO15: 1000 мс
Core1 GPIO25: 500 мс
Запуск и команды по Serial (USB, 115200 бод)
HELP — список команд
MODE CSV|NMEA|JSON|UBX|RAW — формат вывода
PROFILE NORMAL|EMI|URBAN|REMOTE — профиль коррелятора
LOG ON|OFF — дублирующий CSV
REF — опорная точка CPR
SAVE / LOAD / SHOW — сохранить/загрузить/показать настройки (LittleFS)
Загрузка прошивки (UF2)
Ввести Pico в BOOTSEL (зажать кнопку BOOTSEL, подключить USB, отпустить)
Откроется диск RPI-RP2. Скопировать .uf2 на диск (или используйте Upload Method: Picotool в меню Tools)
Если получите OSError: [Errno 22] при копировании — смените USB-порт/кабель, закройте все окна с диском, закройте Serial Monitor, попробуйте другой метод загрузки (Picotool).
Обмен с ESP32S3
Связь: RP2040 TX GPIO4 → ESP32S3 RX GPIO42, RP2040 RX GPIO5 → ESP32S3 TX GPIO41, GND общий
Скорость: 921600 бод (RP2040), на ESP32S3 установите ту же
Структура пакета для ESP32S3 (ваш формат):
fo.addr = receivedPacket.addr;
fo.Squawk = atoi(receivedPacket.squawk);
memcpy(fo.flight, receivedPacket.flight, sizeof(receivedPacket.flight));
fo.altitude / fo.pressure_altitude — метры (если ваши датчики/алгоритм выдают в футах — переведите 1 ft = 0.3048 m)
fo.speed — км/ч (из узлов: km/h = kt × 1.852)
fo.course — градусы
fo.vert_rate — м/мин (из фт/мин: m/min = fpm × 0.3048)
fo.latitude / fo.longitude — градусы
fo.seen — время последней отправки (мс)
fo.timestamp — now()
fo.signal_source = 1
fo.aircraft_type = 9
